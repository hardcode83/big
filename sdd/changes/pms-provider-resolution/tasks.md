# Tasks: pms-provider-resolution

Orden pensado para que el sistema quede funcionando al final de cada sección. Las secciones 2 y 3 son independientes del cifrado y del esquema, así que van primero: mueven la forma del puerto mientras nada depende todavía de credenciales.

Cada tarea incluye su test (regla de `steering/testing.md`). No hay endpoint nuevo ni cambiado en todo el change, así que **no hay que regenerar `backend/openapi.json`** — el workflow `api-contract` no tiene nada que ver aquí.
