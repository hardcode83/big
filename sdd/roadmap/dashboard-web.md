# dashboard-web

[FE] dashboard API agregado + FE: property cards, detalle + timeline (PRD §26.15-17, §9, §24). **El login y la sesión salieron a `frontend-auth-session`** el 2026-08-07: son independientes de la API agregada y bloquean cualquier pantalla real, así que colgarlos de aquí retrasaba lo que ya se puede hacer. Lo que queda es **la API agregada y el cambio del mock**: `frontend/features/dashboard/data/dto.ts:11-12` apunta a `/api/v1/properties`, `/properties/{id}/dashboard` y `/timeline/{property_id}`, y **ninguno de los tres existe** — `backend/app/main.py:51-58` monta solo auth, users, reservations, integrations y tenants, y ni `app/properties/` ni `app/timeline/` contienen `APIRouter`, así que tampoco están en `backend/openapi.json` ni en los tipos generados. Con los tres en pie, `frontend/features/dashboard/data/index.ts:16` pasa de `new MockDashboardSource()` a la implementación HTTP en una línea, y **ese es el instante en que se cumple la condición de disparo #1 de `api-ingress-routing`** (alcance reducido el 2026-08-07 al separar el login)
